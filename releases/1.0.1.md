# Proyecciones SVG 1.0.1

**Versión estable para Windows, Linux y macOS con Python 3.10 y 3.14.** Licencia MIT. Código y descargas públicos, sin iniciar sesión.

Esta revisión cierra la validación de plataformas: incorpora macOS en `PLATFORMS.json` y en las instrucciones de la skill, y añade la guía de instalación y verificación de sumas para macOS en la landing. Conserva el generador geométrico de 1.0.0, sus curvas, cotas y límites. El ZIP 1.0.0 permanece disponible sin modificaciones.

## Validación

La matriz completa de GitHub Actions exige seis combinaciones de sistema/Python, 87 pruebas por combinación (69 de geometría y 18 de distribución), sin fallos ni omisiones, y el mismo SHA-256 del ZIP en todas ellas. Chromium y Firefox comprueban tres modelos con 24 ángulos cada uno: 144 comprobaciones sobre Linux. La comprobación de la landing también se ejecuta en CI.

`release-readiness.json` adjunto conserva el commit, las versiones de Python, sistemas, arquitecturas y resultados efectivos. Esta evidencia describe los entornos probados; no afirma haber probado todas las versiones o arquitecturas de cada sistema operativo. La sección final enlaza la ejecución que aprueba exactamente este paquete.

## Instalación

Descarga `proyecciones-svg-1.0.1.zip`, `install_skill.py` y `SHA256SUMS` de esta release. Comprueba las sumas y ejecuta:

```sh
python install_skill.py proyecciones-svg-1.0.1.zip --skills-dir RUTA_A_CODEX/skills
```

En macOS y Linux usa `python3` si corresponde. Para actualizar añade `--update`: el instalador conserva una copia de la versión anterior fuera de la carpeta de descubrimiento de skills. Reinicia Codex para que descubra la skill instalada.

## Alcance

Genera alzado, planta, perfil y giros SVG desde un único modelo JSON, interpretado por el agente a partir de una descripción, croquis o vistas. Admite perfiles extruidos, poliedros y determinados prismas convexos con hasta cuatro taladros pasantes comunicados. No necesita paquetes Python externos ni un motor 3D.

Las cotas son generales y no constituyen un plano completo para fabricación. Las bocas cilíndricas son elipses analíticas; algunas curvas interiores y clips tienen tolerancia gráfica nominal de 0,025 píxeles del SVG original. Los contratos y límites completos acompañan al paquete.

# Proyecciones SVG 1.2.0

**Cortes SVG y exportación GLB, 3MF y STL, incluidos hasta cuatro taladros cilíndricos comunicados.** Licencia MIT. La publicación exige Windows, Linux y macOS con Python 3.10 y 3.14, sobre el mismo ZIP instalado.

## Novedades

- `--sections` añade cortes planos de cuerpos convexos, con material rayado y unión de vaciados en blanco. El visor incluye controles para las guías auxiliares.
- `--export-glb`, `--export-3mf` y `--export-stl` generan mallas de perfiles extruidos simples, poliedros convexos y los constructores taladrados documentados. Los cilindros se restan como una unión y sus paredes enterradas se eliminan.
- GLB usa metros con Y arriba. 3MF declara milímetros con Z arriba; STL exporta coordenadas en milímetros por convención. `--unit-mm` fija una equivalencia común para las mallas y Cota.
- `--mesh-tolerance-mm` controla la flecha radial de los cilindros facetados, por defecto 0,02 mm. El informe registra resolución, volumen, topología y unidades. Una precisión que excede el presupuesto se rechaza explícitamente.
- Se conservan las tres vistas, el giro SVG, el JSON y la exportación `.cota`. Activar las mallas mantiene idénticos esos productos generados con los mismos parámetros.
- Se incluyen una rampa, un bloque y una escalera de ejemplo. La landing añade cortes, descargas GLB/3MF/STL de las cuatro piezas y una guía para usuarios técnicos y no técnicos.

## Instalar y usar

Descarga el ZIP, el instalador y `SHA256SUMS` desde esta release. Después de comprobar las sumas:

```sh
python install_skill.py proyecciones-svg-1.2.0.zip --skills-dir RUTA_A_CODEX/skills --update
```

En Linux/macOS usa `python3` si corresponde. `--update` conserva una copia de la versión anterior. Reinicia Codex para descubrir la actualización.

SVG, cortes, Cota y mallas sin taladros siguen funcionando con Python estándar. **Sólo las mallas taladradas** requieren instalar la dependencia opcional en el intérprete que ejecutará el generador, preferentemente en un entorno virtual:

```sh
python -m pip install --only-binary=:all: -r <skill>/requirements-mesh.txt
python <skill>/scripts/generar.py <skill>/assets/cuatro-taladros.json --output-dir salida --viewer --sections --export-cota --export-glb --export-3mf --export-stl
```

Se fija Manifold 3.5.4, con NumPy como dependencia. La skill no instala esos paquetes automáticamente ni los redistribuye dentro del ZIP.

## Validación y alcance

Cada una de las seis combinaciones de plataforma/Python ejecuta **159 pruebas Python**, sin omisiones, dos pruebas con el motor fijado de Cota 1.0.0 y la comprobación GLB/3MF/STL generada desde el ZIP instalado. Se contrastan topología cerrada, escala, volumen, material y vacíos en el cruce. Las pruebas de mallas incluyen siete ejemplos taladrados, cambios de unidades y escalas de `1e-8` a `1e6` con tolerancia proporcional.

Chromium y Firefox comprueban tres modelos y 24 ángulos por modelo: 144 comprobaciones sobre Linux, con movimiento reducido y ancho de 320 píxeles. El validador oficial de glTF comprueba los GLB de los tres módulos y de la pieza de cuatro taladros. La publicación exige un ZIP idéntico entre las seis combinaciones y evidencia vinculada al mismo commit y SHA-256.

Se mantienen las restricciones geométricas documentadas: bocas completas separadas dentro de las caras, taladros pasantes y ejes concurrentes para los cruces. No se añaden agujeros ciegos, salidas laterales ni reparación de mallas CAD arbitrarias. El límite radial de facetado no es una tolerancia de fabricación ni limita por sí solo el error de todas las curvas de intersección. GLB/STL utilizan posiciones float32; los casos que colapsan se rechazan.

La validación local adicional incluye importación de 3MF/STL en PrusaSlicer. No se han laminado ni impreso físicamente las piezas. Los modelos no incluyen perfil de impresora, G-code, colisiones, texturas ni animación de personajes. Cota sigue siendo un intercambio de un solo sentido hacia su versión 1.0.0; las ediciones allí no regeneran los SVG.

`release-readiness.json` identifica los entornos efectivos, resultados y sumas. La sección final enlaza la ejecución de CI que aprueba esta entrega. Las releases anteriores se conservan.

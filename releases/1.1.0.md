# Proyecciones SVG 1.1.0

**Exportación opcional a Cota, validada en Windows, Linux y macOS con Python 3.10 y 3.14.** Licencia MIT. Código y descargas públicos, sin iniciar sesión.

`--export-cota` añade `modelo.cota` junto a las tres vistas, la vista oblicua, el giro SVG y el visor solicitados. Los SVG y el visor conservan exactamente los mismos bytes al activar esta opción. El generador sigue usando únicamente la biblioteca estándar de Python; no instala ni ejecuta Cota para exportar.

- Convierte las medidas a milímetros. Para unidades relativas admite `--cota-unit-mm N`, una equivalencia física explícita.
- Conserva el perfil de la cuña y los ejes y diámetros de los taladros. Construye las cubiertas inclinadas mediante una extrusión recortada por una caja orientada, evitando el problema de orientación de `LOFT` detectado en Cota 1.0.0.
- Registra las sumas del archivo exportado e incorpora la salida a los presupuestos y las comprobaciones de sobrescritura.
- La landing ofrece archivos Cota de sus cuatro ejemplos y explica cómo abrirlos y pedir esta salida.

## Validación del paquete

Cada una de las seis combinaciones ejecuta 99 pruebas Python y dos pruebas con el motor real de Cota 1.0.0, revisión `e43e37de4017e6b87f72180b0f4e6162943f4880`. Estas últimas instalan el ZIP exacto, generan la cuña y la pieza de cuatro agujeros y comprueban dimensiones, volumen bajo la cubierta y puntos de material/vacío en los conductos. La publicación exige estos seis informes vinculados al mismo commit y SHA-256 del paquete, sin pruebas omitidas.

Chromium y Firefox comprueban además tres modelos y 24 ángulos por modelo: 144 comprobaciones en Linux, con visor portable, movimiento reducido y ancho de 320 píxeles. `release-readiness.json` conserva los entornos y resultados efectivos. La sección final enlaza la ejecución de CI que aprueba esta entrega.

## Instalación y uso

Descarga `proyecciones-svg-1.1.0.zip`, `install_skill.py` y `SHA256SUMS`. Comprueba las sumas y ejecuta:

```sh
python install_skill.py proyecciones-svg-1.1.0.zip --skills-dir RUTA_A_CODEX/skills --update
```

En Linux y macOS usa `python3` si corresponde. `--update` conserva una copia de la instalación anterior. Reinicia Codex para descubrir la versión instalada.

Pide: «Genera las tres vistas y el giro SVG; añade un archivo Cota para editar el volumen». Para el comando directo:

```sh
python <skill>/scripts/generar.py modelo.json --output-dir salida --viewer --export-cota
```

## Alcance

El destino de intercambio es Cota 1.0.0, esquema JSON 1. Cota usa mallas para evaluar los sólidos; los cilindros exportados tienen 64 segmentos radiales. Las ediciones posteriores en Cota no actualizan el JSON ni los SVG originales. La lámina acotada y la animación se entregan como SVG separados; el archivo Cota contiene el volumen editable. Este intercambio es de un solo sentido y no certifica precisión CAD ni un plano de fabricación.

La validación de navegador se ejecuta en Linux; la del motor Cota se ejecuta en las seis combinaciones. La evidencia describe los sistemas y arquitecturas probados, no todas las variantes de cada plataforma. Las releases anteriores permanecen disponibles sin modificaciones.

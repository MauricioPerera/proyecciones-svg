# Proyecciones SVG 1.0.0

**Versión estable para Windows y Linux con Python 3.10 y 3.14. macOS pendiente de validación.** Licencia MIT. La release se publica en el repositorio privado existente.

Genera alzado, planta, perfil y giros vectoriales desde una descripción o croquis interpretado por el agente. Todas las vistas proceden de un único modelo JSON reproducible; no requiere imágenes generadas ni un motor 3D.

- Perfiles extruidos, poliedros cerrados y prismas convexos con cubierta inclinada y hasta cuatro taladros cilíndricos pasantes comunicados, dentro de los contratos documentados.
- Curvas y cotas generales conservadas al cambiar de escala; validación local de caras para admitir piezas esbeltas.
- CLI común con presupuestos de tiempo/salida y visor HTML autónomo con control de ángulo, reproducción manual y aristas ocultas.
- Instalador con sumas SHA-256 y respaldo al actualizar. Licencia MIT incluida en el paquete.

Requiere Python 3.10 o posterior. El uso de la skill y sus productos no necesita Node ni dependencias Python externas. Las pruebas de navegador usan Playwright exclusivamente durante el desarrollo.

## Instalación

Descarga `proyecciones-svg-1.0.0.zip` y `install_skill.py` de los archivos de esta release. Comprueba el archivo `.sha256` y ejecuta:

```sh
python install_skill.py proyecciones-svg-1.0.0.zip --skills-dir RUTA_A_CODEX/skills
```

Si ya existe una versión, añade `--update`. La anterior se conserva fuera del directorio de descubrimiento de skills; para volver a otra versión instala su ZIP con `--update`.

## Alcance

Las cotas son generales y no constituyen un plano completo para fabricación. Las bocas de los taladros son elipses analíticas; las curvas interiores de distinto diámetro y los clips se aproximan con una tolerancia gráfica nominal de 0,025 píxeles del SVG original. No se admiten superficies libres ni todas las configuraciones posibles de agujeros. Los límites completos acompañan a la skill.

La sección final y `release-readiness.json` describen las cuatro combinaciones aprobadas de Windows/Linux con Python 3.10/3.14, Chromium/Firefox en Linux y la igualdad del SHA-256 del ZIP entre plataformas. Las pruebas se ejecutan localmente y en un VPS autorizado por SSH, sin GitHub Actions. El paquete incluye `PLATFORMS.json` con macOS expresamente pendiente.

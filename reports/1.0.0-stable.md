# Alcance de la versión estable 1.0.0

Actualización posterior: la [matriz completa](1.0.0-full-matrix.json) aprobó también macOS sobre el mismo ZIP 1.0.0. La [versión 1.0.1](1.0.1-stable.md) incorpora esa compatibilidad en el paquete y vuelve a aprobar las seis combinaciones. El texto siguiente conserva el alcance original de publicación.

23 de octubre de 2026. El usuario autorizó publicar la estable para Windows y Linux y dejar macOS pendiente de validación. Se publicó inicialmente en un repositorio privado; después el usuario autorizó hacer públicos el [repositorio y las descargas](https://github.com/MauricioPerera/proyecciones-svg). El ZIP estable conserva los mismos bytes y SHA-256.

| Alcance | Comprobación requerida |
| --- | --- |
| Windows / Python 3.10 y 3.14 | Suite completa de geometría y distribución/release |
| Linux / Python 3.10 y 3.14 | Misma suite, ejecutada en Ubuntu 24.04 mediante SSH |
| Chromium y Firefox en Linux | Tres modelos por motor y 24 ángulos por modelo: 144 comprobaciones |
| Paquete | Mismo ZIP y SHA-256 en las cuatro combinaciones |
| macOS / Python 3.10 y 3.14 | Pendiente; no se presenta como plataforma validada |

El perfil `windows-linux` permite aprobar únicamente este alcance y lo registra en la evidencia. El perfil predeterminado `all` continúa exigiendo las seis combinaciones; los resultados de Windows/Linux no lo aprueban. Ambos rechazan commits diferentes, archivos alterados, pruebas fallidas u omitidas y evidencias incompletas de navegador.

La publicación adjunta `release-readiness.json` con el commit y los resultados efectivos del paquete final. Las cotas siguen siendo generales y las aproximaciones gráficas conservan los límites documentados. La licencia, las notas y `PLATFORMS.json` acompañan al ZIP; este cambio no añade capacidades geométricas ni afirma compatibilidad validada con macOS.

## Retomar cuando haya presupuesto

```sh
gh workflow run verify.yml --repo MauricioPerera/proyecciones-svg --ref main
gh run list --repo MauricioPerera/proyecciones-svg --workflow verify.yml --branch main
```

Después de que esa ejecución y `Ready for release` terminen correctamente, desde `main` limpio y sincronizado:

```sh
python -B tools/prepare_release.py --repo MauricioPerera/proyecciones-svg --create-draft
```

El comando descarga la evidencia de CI y comprueba commit, versión y sumas antes de crear un borrador con ZIP, instalador, licencia y notas. No permite reemplazar una versión publicada. La publicación definitiva se realiza después de revisar el borrador.
